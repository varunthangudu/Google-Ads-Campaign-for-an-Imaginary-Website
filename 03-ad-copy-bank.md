# Ad copy bank — Week 2 deliverable

Four Responsive Search Ads, one per ad group, each with 15 headlines and 4 descriptions. Google assembles up to three headlines and two descriptions per impression, so every headline has to read sensibly in any position. Each asset below names the job it does, because a bank of 15 interchangeable slogans teaches you nothing when you later read the asset performance report.

Character limits are enforced by the build script that generated this file (`build/make_adcopy.py`): headlines 30, descriptions 90, display paths 15.

## Pinning decisions

Only two assets are pinned, because pinning shrinks the number of combinations Google can test and usually costs Ad Strength:

- Headline 1 is pinned to position 1 in every ad group so the ad always opens with the service the searcher typed. Message match to the query is worth more than combination variety.
- The price headline is pinned to position 2 in AG1 and AG4, where the ticket is large enough that an unqualified click is expensive.
- Everything else is left unpinned so the system can learn.

## Display creative

Seven banner sizes are in `assets/banners/`, covering the placements that carry most Display inventory: 300x250, 336x280, 728x90, 300x600, 160x600, 320x50 and 320x100. All seven share one message so remarketing reinforces the landing page rather than introducing a new offer.
